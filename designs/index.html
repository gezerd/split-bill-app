$ Split Bill — Screens

Each screen is a standalone HTML page sharing one styles.css. Open any page directly to inspect exact spacing, color, and type in dev tools, or read the markup — class names map 1:1 to the stylesheet.

01Upload — idle
Dropzone idle — receipt scan entry point.
01Upload — scanning
After a file drops: spinner + “Scanning with AI…” (~2s).
01Upload — processed
Scan complete: accent check + “5 items found!” before advancing.
02Assign — all assigned
Every quantity claimed (Large Soda ×3 split 2 / 1) → all cards highlighted, “All assigned ✓”.
02Assign — partial
Cheeseburger ×2 (1 share) & Large Soda ×3 (2 shares) under-filled → not highlighted, “2 unassigned”.
02Assign — add item
Dashed “Add missing item” card opens a modal for name, price each, quantity stepper & removable modifier tags.
02Assign — edit item
The ✎ on a card reopens the same modal pre-filled to change name, price, quantity, or modifiers.
02Assign — delete item
The ✕ opens a confirm dialog naming the item; Delete removes it and clears its assignments.
03Tax & Tip — with tip
“Add tip” selected → percentage presets + Custom shown, 20% tip, live Total pill.
03Tax & Tip — no tip
“No tip” selected → percentage/custom options hidden, tip is $0, Total drops to $27.02.
04Breakdown — Cards
Per-person settlement cards (default layout).
04Breakdown — Receipt
Alternate paper-receipt layout with torn edges.
